# Phase 006 selected direction

## Selected primary concept

Primary concept: `concept-01-diary-desk.png`

Direction name: `sailei-pink-diary-desk`

## Why this is selected

Concept 01 is the closest match to the user’s stated direction:

- Pink first
- Anime first
- Personal site second
- Strong component language
- Sailei companion feeling
- Homepage modules already map to real site needs
- No black terminal mood

## What to preserve

- Milk-white and sakura-pink base
- Soft fixed anime background impression
- Large galgame-style hero dialogue
- Sticker task cards labeled like files
- Companion profile panel
- Polaroid recent moments
- Category sticker shelf
- Pink glass panels with paper grain
- Tiny cyan and warm gold accents

## What to change during implementation

- Replace generated fake text with real Jlemonz copy
- Reduce module density for mobile
- Use existing Sailei and brand assets instead of generated character art as production assets
- Recreate UI through Astro, CSS, and local assets
- Keep animation subtle
- Keep text readable on 390, 768, 1280, 1920, 2560, and 3840 widths

## Blend rules

### From Concept 02

- Use visual-novel dialogue for Hero and empty states
- Use character nameplate styling
- Use choice-button logic sparingly for navigation or page actions

### From Concept 03

- Use sticky-note feed for moments
- Use polaroid cards for image moments
- Use channel tabs for `碎片 / 项目 / 生活`
- Keep `瞬间` visually separate from `笔记`

### From Concept 04

- Use mission files for projects
- Use energy bars for progress
- Use roadmap ribbon for next steps
- Keep HUD light, pink, and readable

## Explicit rejects

- Do not use Concept 02 as the whole site shell. It is too game-screen heavy.
- Do not use Concept 03 for notes. It belongs to moments.
- Do not use Concept 04 as an enterprise dashboard. It needs diary softness.
- Do not use generated character art as production Sailei replacement without a later asset review.
