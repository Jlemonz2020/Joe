# Phase 004 page copy direction

## Copy principles

Future copy should sound like a personal technical diary with Sailei presence. It should avoid product-marketing claims, engineering placeholders, and generic blog language.

Use:

- Short direct sentences
- Concrete technical nouns when useful
- Warm diary language
- Page-specific verbs
- Soft anime UI labels when they clarify the component

Avoid:

- “这里展示”
- “暂无数据”
- “敬请期待”
- “功能完善中”
- “标题再长也会稳稳排版”
- Enterprise dashboard language
- Black terminal language as the default tone

## Global labels

| Surface | Label | Copy direction |
|---|---|---|
| Navigation home | 首页 | Entry and current state |
| Navigation moments | 瞬间 | Short diary feed |
| Navigation archive | 笔记 | Searchable knowledge archive |
| Navigation projects | 项目 | Public task files |
| Navigation about | 关于 | Profile and contact |
| Search title | 找一条旧记录 | Keep, but style as pink record lookup |

## Homepage draft direction

### Hero

Use the existing idea:

> 在 Pi5、Linux、硬件和 AI 之间，整理那些值得回看的折腾。

Later copy can add a Sailei dialogue line, for example:

> 今天也把线索贴好，明天回来还能接上。

### Status cards

Keep the meanings but convert labels into diary file language:

| Current idea | Future label direction | Body direction |
|---|---|---|
| RECAP | FILE 01 / 回看 | Bugs, commands, and fixes become readable notes |
| TRACE | FILE 02 / 线索 | Unfinished debugging gets a visible trail |
| DAILY | FILE 03 / 日常 | Small non-project fragments still count |

## Moments copy direction

Hero:

> 随手贴下今天的折腾、灵感和小事，给时间线留一点粉色标记。

Empty state:

> 今天的便签还空着。等下一次折腾有了火花，再把它贴到这里。

Card microcopy:

- `贴上这条`
- `生活碎片`
- `项目留痕`
- `刚刚补完`
- `今天的轻记录`

## Notes copy direction

Hero:

> 长文、调试和学习笔记收进资料库，下一次遇到同类问题时能直接翻回现场。

Empty state:

> 资料夹还没放入公开笔记。等第一篇长记录整理好，赛蕾会把它钉在这里。

Card microcopy:

- `打开笔记`
- `调试记录`
- `学习索引`
- `命令回看`
- `资料入库`

## Projects copy direction

Hero:

> 服务、硬件和页面改造都按任务档案整理，保留状态、进展和下一步。

Empty state:

> 任务板暂时没有公开项目。等下一个服务或硬件实验整理完成，它会出现在这里。

Card microcopy:

- `任务档案`
- `同步中`
- `下一步`
- `公开复盘`
- `能量条`

## About copy direction

Hero:

> 一个在 Linux、硬件和 AI 之间慢慢补课的人，也把这座小站当成长期练习场。

Profile microcopy:

- `当前状态`
- `长期补课`
- `公开联系`
- `留言`
- `学习方向`

## Detail page copy direction

Post detail should use reading language:

- `公开笔记`
- `回到资料库`
- `笔记评论`
- `正文正在加载`

Project detail should use task language:

- `任务详情`
- `回到任务板`
- `项目评论`
- `项目记录正在加载`

## Writing review checklist

- Each page does one job
- Sentences stay short enough to read aloud
- Copy names the action and context
- No placeholder tone
- No black-terminal default vocabulary
- Moments and notes never share the same empty copy
- Empty states sound intentional, not broken
