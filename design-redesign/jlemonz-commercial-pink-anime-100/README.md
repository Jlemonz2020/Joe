## Goal

Rebuild Jlemonz as a commercial-grade pink anime Sailei diary site.

The existing UI is not a constraint. The redesign may discard the current frontend interface and rebuild it with Astro, while preserving existing APIs, backend, database, admin system, public content, legacy URLs, and Sailei/brand assets.

## Non-Negotiables

- Default visual direction: `sailei-pink-diary`.
- Anime-first, personal-site-second, technical-readability-third.
- No full-site black terminal direction.
- No "background swap only" redesign.
- No backend, database, or admin rewrite in this goal.
- No copyright-unclear external hotlinked assets.
- Every phase must be pushed to GitHub.
- User review is a required gate before moving past visual direction and major page modules.
