## 11. 软件的主要功能

```text
本软件是一套面向个人长期使用的知识内容管理与面试训练系统，主要由前台展示端和后台管理端组成。前台提供首页、小记、瞬间、项目、面试、关于等页面，用户可以浏览文章内容、查看项目进度、检索碎片记录、阅读项目复盘，并在面试模块中按分类和标签进行题库训练。小记模块用于保存较完整的文章和阶段性总结；瞬间模块用于记录灵感、日常片段和项目痕迹，支持分类筛选与内容搜索；项目模块用于展示项目名称、摘要、进度、状态、更新时间和详情内容；面试模块支持题目分页、分类树、标签筛选、答案展开、追问查看、工程实例展示、完成勾选和见解保存。系统还集成天气、音乐推荐、招聘会信息、科技热点等辅助信息卡片，由后端统一缓存后提供给前端，减少外部接口加载慢对页面体验的影响。后台管理端用于维护文章、瞬间、项目、面试题、站点文案、页面装修和展示配置，支持内容发布、隐藏、恢复、删除、排序和版本记录。系统通过统一接口读取数据，前台只展示公开状态内容，并在接口异常时提供可渲染的兜底状态，保证网站在正式上线环境下能够稳定展示和持续维护。
```

## 12. 软件的技术特点

```text
采用原生前端与Node.js接口分层设计，支持缓存快照、资源版本控制、题库分页筛选、移动端适配和异常兜底。
```
