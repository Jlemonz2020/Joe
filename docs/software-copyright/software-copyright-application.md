## 二、软件概述

Joe 个人知识内容管理与面试训练系统是一套围绕个人长期记录、项目复盘、技术学习和面试准备构建的网站系统。系统前台提供首页、瞬间、小记、项目、面试、关于等页面，后台提供内容维护、站点文案配置、项目管理、瞬间管理、面试题库维护、页面装修和系统健康检查等功能。

本系统不是单一静态展示页，而是把个人博客、项目档案、碎片记录、面试题库、外部信息聚合和后台配置整合到同一个站点中。前台页面注重轻量、柔和的阅读体验，后台侧重内容可维护、数据可复用、接口可缓存和上线后稳定运行。

系统使用 Node.js 提供后端接口，MySQL 存储文章、项目、瞬间、面试题、用户见解和站点配置，Redis 用于缓存天气、音乐、招聘会、科技热点等外部数据快照。前端通过统一 API 封装读取数据，并在网络异常时提供本地预览或柔和兜底状态，减少页面空白和阻塞。

## 三、开发背景

个人知识网站在长期使用中容易遇到几个问题：内容分散、项目复盘不连续、碎片想法难以沉淀、面试训练资料质量参差不齐、外部信息 API 加载慢且不稳定。Joe 系统的开发目标，是把这些日常需求放在一个长期可维护的 Web 项目中，使个人内容既可以展示，也可以持续更新、筛选、检索和复盘。

系统的设计重点包括：

1. 前台页面保持一致的视觉风格，避免每个页面割裂。
2. 内容数据由后台统一维护，刷新页面后不依赖本地浏览器临时数据。
3. 面试题库支持分类、标签、分页、答案、追问、实例和个人见解。
4. 天气、音乐、招聘会、科技热点等外部信息由后端缓存后再提供给前端。
5. 静态资源使用版本号管理，避免页面刷新时加载旧样式或旧脚本。
6. 项目归档版本排除数据库、密钥、服务器口令和私有上传缓存。

## 四、主要功能模块

### 1. 前台首页模块

首页用于展示站点整体入口、最新内容、项目进度、瞬间摘要和公共页脚。页面通过统一的站点配置读取标题、文案、导航和展示区块，支持后端更新后前台自动同步。

主要功能：

- 展示站点主视觉、导航入口和核心内容摘要。
- 聚合最新小记、项目、瞬间等内容。
- 使用统一页脚组件，保证各页面风格一致。
- 通过静态资源版本号控制 CSS 和 JS 缓存。

### 2. 小记与文章模块

小记模块用于承载较完整的文字内容。系统支持文章列表、文章详情、摘要展示、分类信息、文章上下篇跳转等功能。前台只展示已发布内容，后台可维护文章草稿、状态和排序。

主要功能：

- 小记列表展示标题、摘要、时间等信息。
- 文章详情页展示正文内容。
- 支持文章发布、隐藏、恢复和删除状态管理。
- 支持后台维护文章内容与版本记录。

### 3. 瞬间模块

瞬间模块用于记录短内容、灵感、项目痕迹和日常片段。前台支持按“碎片 / 痕迹 / 日常”切换筛选，同时支持内容搜索。右侧动态卡片可展示思考题等轻量内容。

主要功能：

- 支持短文本、标签、图片链接和发布时间。
- 支持分类筛选和搜索。
- 支持后台发布、隐藏、恢复和删除。
- 前端通过接口读取已发布瞬间，避免仅本地可见。

### 4. 项目模块

项目模块用于展示个人项目档案。列表页采用左侧主内容、右侧辅助信息的布局，项目卡片可展示进度条、状态、摘要和更新时间。详情页延续小记页的阅读结构，适合记录项目目标、过程、复盘和阶段成果。

主要功能：

- 项目列表展示项目名称、摘要、进度和状态。
- 项目详情展示完整内容、项目进展和复盘。
- 后台支持项目新增、编辑、隐藏、恢复和排序。
- 右侧栏集成招聘会信息卡，按校招和社招展示近期线下场次。

### 5. 面试题库模块

面试模块是系统中较复杂的学习训练部分。它支持分类树、标签筛选、分页、题目详情、答案展开、追问展示、实例展示、完成勾选和公开见解。题库数据存储在后端，其他用户访问时可以看到同一套公开题目和已保存的公开见解。

主要功能：

- 支持 FOC、控制与嵌入式、项目实战等方向的题库分类。
- 支持右侧分类树和多标签筛选。
- 支持题目分页与稳定混排，避免同类题目集中展示。
- 每道题可包含标准答案、追问、面试官关注点、口述模板、常见错误和工程实例。
- “答案”和“实例”按钮互相独立，实例可单独展开。
- 支持“我的见解”写入后端，让其他访问者也能看到公开内容。

### 6. 外部信息聚合模块

系统包含多个轻量信息聚合卡片，包括天气、DDV 歌单、动漫推荐、科技热点、招聘会等。这些数据不直接由前端频繁请求第三方，而是由后端接口进行缓存、格式化和兜底后提供给前端。

主要功能：

- 天气卡支持浏览器定位、IP 兜底定位和默认城市兜底。
- DDV 歌单支持每日轮换，避免长期固定几首歌曲。
- 招聘会卡聚合全国招聘会、学校就业网和地方人社信息。
- 科技热点卡聚合 GitHub、Hacker News 等公开信息。
- 后端使用缓存快照减少外部 API 慢加载对页面的影响。

### 7. 后台管理模块

后台管理用于维护文章、瞬间、项目、面试题、站点文案和页面装修。系统保留内容版本和操作日志，便于回滚和排查。

主要功能：

- 内容管理：文章、小记、瞬间、项目、面试题维护。
- 页面装修：站点标题、导航、页面小字、图库、页脚等配置。
- 系统配置：缓存策略、站点文本、资源版本、健康检查。
- 数据安全：前台只展示公开状态内容，后台操作受权限控制。

## 五、系统架构说明

系统采用前后端分层设计：

- **前端层**：由 HTML、CSS、JavaScript 构成，负责页面结构、交互、异步请求和状态渲染。
- **接口层**：Node.js 后端提供 REST 风格接口，统一处理数据读取、过滤、分页、缓存和异常兜底。
- **数据层**：MySQL 存储业务数据，Redis 存储短周期缓存与外部 API 快照。
- **部署层**：Nginx 负责静态资源访问和请求转发，Node.js 服务运行在容器环境中。

核心数据流：

1. 用户打开前台页面。
2. 前端加载带版本号的 CSS 和 JS。
3. 前端通过统一 API 请求内容数据。
4. 后端优先读取缓存；缓存不存在时访问数据库或外部数据源。
5. 后端格式化数据后返回前端。
6. 前端渲染卡片、列表、详情、按钮状态和兜底提示。

## 六、技术特点

### 1. 统一 API 封装

前端请求集中走统一函数，便于处理本地静态预览、错误兜底和接口差异。这样即使部署环境、静态预览环境不同，页面仍能保持基本可用。

### 2. 后端缓存快照

天气、音乐、招聘会、科技热点等数据存在外部 API 慢、失败或格式变化的问题。系统通过后端缓存快照处理这些数据，前端只读取站内接口，减少首屏等待时间。

### 3. 内容状态隔离

文章、瞬间、项目、面试题等内容均带有发布状态和删除标记。前台只展示公开内容，后台保留管理、恢复和版本记录能力。

### 4. 面试训练结构化

题库不只保存题干，还保存答案、追问、标签、实例和用户见解。实例结构统一为“具体例子、解决方法、原因分析、思路总结”，便于面试复盘和口述训练。

### 5. 缓存版本控制

静态资源链接包含版本号。前端更新后同步 bump 版本，避免浏览器继续读取旧脚本、旧样式，减少“刷新瞬间看到旧页面”的问题。

### 6. 柔和异常处理

当外部 API 或后端数据暂时不可用时，前端不直接崩溃，而是展示“同步中”“暂时不可用”“实例生成中”等状态，保证主体页面仍可阅读。

## 七、数据库设计概述

系统数据库主要包含以下几类数据表：

- **内容表**：文章、小记、瞬间、项目等内容数据。
- **面试题表**：题干、答案、追问、实例、标签、难度、状态等。
- **分类关系表**：面试目标树、题目与目标分支关系。
- **互动表**：用户见解、完成记录、点赞等互动信息。
- **配置表**：站点文案、页面装修、主题配置、导航配置。
- **版本表**：内容版本、配置版本、操作审计记录。

提交软著材料时不需要提交真实数据库内容，只需要说明数据结构和功能逻辑即可。

## 九、操作流程

### 前台用户流程

1. 打开网站首页。
2. 通过导航进入瞬间、小记、项目、面试或关于页。
3. 在小记页阅读文章，在瞬间页浏览短内容，在项目页查看项目进度。
4. 在面试页选择分类或标签，查看题目、答案、追问和实例。
5. 在题目下方填写见解，保存后其他访问者可以看到。

### 后台管理流程

1. 管理员登录后台。
2. 进入内容管理模块，新增或编辑文章、瞬间、项目。
3. 进入面试题库模块，维护题目、标签、答案和实例。
4. 进入页面装修模块，调整站点文案、页面小字、导航和展示项。
5. 保存后，前台通过接口读取最新发布内容。
