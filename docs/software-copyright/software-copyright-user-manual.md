# Joe 个人知识内容管理与面试训练系统 V1.0 用户操作说明书

## 1. 软件简介

Joe 个人知识内容管理与面试训练系统是一套用于个人网站展示、内容维护、项目复盘和面试训练的 Web 系统。系统分为前台访问端和后台管理端。前台面向普通访问者，提供内容浏览、项目查看、面试题训练和信息卡片；后台面向管理员，用于维护文章、瞬间、项目、题库和页面配置。

## 2. 前台功能说明

### 2.1 首页

用户进入首页后，可以看到站点标题、导航入口、最新内容摘要、项目入口、瞬间入口和统一页脚。首页用于快速了解网站主题，并进入各个功能页面。

操作步骤：

1. 打开网站首页。
2. 查看页面顶部导航。
3. 点击“小记”“瞬间”“项目”“面试”“关于”等入口。
4. 页面自动进入对应模块。

### 2.2 小记页面

小记页面用于展示较完整的文字内容。用户可以浏览文章列表，点击任意文章进入详情页。

操作步骤：

1. 点击导航中的“小记”。
2. 浏览文章标题、摘要和发布时间。
3. 点击文章卡片进入详情页。
4. 在详情页阅读正文，并通过上下篇区域继续浏览。

### 2.3 瞬间页面

瞬间页面用于展示短内容、灵感、生活片段和项目痕迹。页面顶部提供三个筛选按钮：碎片、痕迹、日常。

操作步骤：

1. 点击导航中的“瞬间”。
2. 点击“碎片 / 灵机一动”查看全部或碎片内容。
3. 点击“痕迹 / 合理摸鱼”查看项目留痕。
4. 点击“日常 / 是这样的”查看生活日常。
5. 使用页面搜索框搜索瞬间内容。

### 2.4 项目页面

项目页面用于展示个人项目。每个项目卡片包含项目标题、摘要、状态、进度和更新时间。右侧卡片展示近期招聘会信息，并按校招和社招分区。

操作步骤：

1. 点击导航中的“项目”。
2. 查看项目卡片和进度条。
3. 点击项目卡片进入项目详情页。
4. 在右侧“面试招聘会”卡片中查看近期校招、双选会、社招和现场招聘活动。
5. 点击招聘会条目可打开外部来源页面。

### 2.5 面试页面

面试页面用于面试题训练。用户可以选择分类、标签，查看题目、答案、追问和实例，也可以保存自己的见解。

操作步骤：

1. 点击导航中的“面试”。
2. 在右侧分类区选择目标方向，例如 FOC、控制与嵌入式、项目实战等。
3. 使用标签筛选题目，例如“调参”“代码能力”“通信异常”“死机”等。
4. 点击“查看答案”展开标准答案。
5. 点击“实例”展开该题对应的工程实例。
6. 在“我的见解”区域输入自己的理解并保存。
7. 点击完成勾选，记录训练状态。

### 2.6 关于页面

关于页面用于展示站点介绍、图库、音乐推荐、留言和联系信息。音乐推荐卡片由后端缓存每日轮换数据，避免每次刷新都访问外部接口。

操作步骤：

1. 点击导航中的“关于”。
2. 查看站点说明、图片展示和音乐推荐。
3. 阅读页脚歌词和站点信息。
4. 使用留言或联系入口进行互动。

## 3. 后台管理功能说明

### 3.1 登录后台

管理员通过后台入口登录系统。登录成功后可以进入内容管理、页面装修、题库管理和系统检查等功能。

### 3.2 文章管理

文章管理用于新增、编辑、发布、隐藏、恢复和删除小记文章。

操作步骤：

1. 进入后台文章管理。
2. 点击新建文章。
3. 填写标题、摘要、正文、分类和状态。
4. 点击保存。
5. 状态为发布时，前台小记页可以看到该文章。

### 3.3 瞬间管理

瞬间管理用于维护短内容。

操作步骤：

1. 进入后台瞬间管理。
2. 填写瞬间内容、类型和标签。
3. 可选填写图片链接。
4. 点击发布。
5. 前台瞬间页按类型和搜索条件展示。

### 3.4 项目管理

项目管理用于维护项目档案。

操作步骤：

1. 进入后台项目管理。
2. 新建或编辑项目。
3. 填写项目名称、摘要、正文、进度、状态和封面。
4. 调整排序。
5. 保存后前台项目页展示最新内容。

### 3.5 面试题库管理

面试题库管理用于维护题目、答案、追问、实例和标签。

操作步骤：

1. 进入后台面试题管理。
2. 选择题目分类或目标分支。
3. 新增或编辑题干、答案和标签。
4. 填写实例内容，包括具体例子、解决方法、原因分析和思路总结。
5. 保存后前台面试页可读取该题详情。

### 3.6 页面装修

页面装修用于维护前台文案、导航、页面小字、图库和其他展示内容。

操作步骤：

1. 进入后台页面装修。
2. 修改首页、瞬间、小记、项目、面试、关于等页面文案。
3. 配置图库图片链接、显示状态和排序。
4. 保存配置。
5. 前台刷新后加载最新配置。

## 4. 异常提示说明

系统在网络异常或外部接口不可用时，会尽量展示柔和的兜底信息。

- 天气不可用：显示同步失败或默认城市兜底。
- 音乐不可用：显示后端缓存或空态。
- 招聘会不可用：显示“招聘会暂时不可用”。
- 面试实例未生成：显示“实例生成中”。
- 内容为空：显示后台添加内容后的提示。

## 5. 数据安全说明

前台只展示已发布内容。后台数据、接口密钥、服务器口令、数据库连接信息不在前台页面中展示，也不应写入公开仓库。归档代码时应排除环境变量文件、数据库文件、日志、缓存和私密上传目录。

## 6. 维护建议

1. 修改前端文件后同步更新静态资源版本号。
2. 调整外部 API 后先测试接口返回，再测试页面渲染。
3. 面试题库批量更新后检查分类计数、分页、标签和题目详情。
4. 发布前检查控制台错误、资源 404、中文乱码和移动端横向溢出。
