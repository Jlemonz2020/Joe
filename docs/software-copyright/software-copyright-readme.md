# 软著申请材料使用说明

本目录中这次整理好的正式材料如下：

1. `software-copyright-application.md`
   软著申请总说明，包含软件基本信息、开发背景、模块说明、架构说明、技术特点、原创性说明和提交建议。

2. `software-copyright-user-manual.md`
   用户操作说明书，可作为软著提交时的软件说明书基础材料。

3. `software-copyright-source-excerpts.md`
   核心源代码摘录，已避开真实服务器信息、口令、接口密钥、数据库内容和私密配置。

旧文件 `software-copyright-material.md` 是早期草稿，可以作为参考；正式整理建议以上面三份新文件为准。

## 提交前需要你补充的信息

- 著作权人姓名或单位名称。
- 身份证号或统一社会信用代码。
- 开发完成日期。
- 首次发表日期；如果没有正式公开发表，可按实际情况填写未发表。
- 软件全称是否沿用“Joe 个人知识内容管理与面试训练系统”。
- 申请人联系地址、电话、邮箱等表单信息。

## 建议的软件名称

建议名称：Joe 个人知识内容管理与面试训练系统
建议简称：Joe 知识与面试训练系统
建议版本：V1.0

这个名称比“个人博客”更能覆盖你现在的实际功能：小记、瞬间、项目、面试题库、外部信息卡片、后台配置和缓存接口。

## 提交前检查

- 不提交 `.env`、数据库文件、日志、缓存目录。
- 不提交服务器登录口令、第三方 API 密钥、后台账号密码。
- 不提交真实用户数据、私密图片和私密上传附件。
- 源代码材料中外部接口链接可以保留技术说明，但不要放服务器登录信息。
- 如需提交源代码页，建议从 `assets/app.js`、`assets/style.css`、`server.js` 中按连续页整理。
